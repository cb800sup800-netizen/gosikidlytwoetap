# GosiasSupportChat

Локальная копия системы поддержки Госуслуг (gosias.online) с 4 страницами, формой восстановления, Telegram-ботом.

## Стек
- Node.js + Express
- Vanilla HTML/CSS/JS
- Telegram Bot (node-telegram-bot-api)
- JSON storage

## Запуск
1. `npm install`
2. `npm start` (сервер)
3. `npm run bot` (бот)

См. инструкции в проекте.
